# Adventure Dice

Пошаговая игра с элементами выживания в процедурно генерируемом мире, 
разбитом на клетки. Игрок ведёт отряд персонажей через биомы, 
принимает решения, управляет ресурсами и переживает дни.

## Реализованные механики

- **Процедурная генерация** — биомы, структуры, расстановка объектов
- **Отряд персонажей** — переход между бойцами, выбор действий
- **Система ходов и дней** — пошаговое время, смена дня и ночи
- **Сохранение и загрузка** — прогресс сохраняется между сессиями
